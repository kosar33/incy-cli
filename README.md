# incy-cli 🚀

Легковесный консольный клиент VPN для Linux с поддержкой привязки устройств по **HWID** и закрытых подписок экосистемы **Remnawave / INCY / Happ**.

Работает на базе официального ядра **Xray-core** в нативном **TUN-режиме** (трафик всей системы автоматически заворачивается в туннель без необходимости прописывать прокси вручную в браузерах или приложениях).

---

## 💡 Особенности

* **Обход ограничений закрытых клиентов**: нативно передает требуемые заголовки (`User-Agent: INCY/...`, `X-HWID`) и напрямую работает с сырыми Xray JSON-нодами.
* **Постоянный HWID**: генерирует уникальный аппаратный идентификатор при первой инициализации и сохраняет его в конфиг — лимит подключенных устройств у вашего провайдера не расходуется.
* **TUN на всю систему**: создает системный виртуальный адаптер `xray0`, пропуская через VPN вообще весь сетевой трафик (терминал, браузеры, торренты, демоны).
* **Корректный парсинг локаций**: аккуратно извлекает названия стран, городов и эмодзи-флагов из полей `remarks`, `name` и `ps`.
* **Автономия (systemd)**: поддержка автозапуска при загрузке системы и ежедневного фонового обновления нод через `systemd.timer`.
* **Мультидистрибутивность**: работает одинаково на Arch Linux, Ubuntu, Debian, Fedora, Alpine, openSUSE и др.
* **Zero Dependencies**: написан на стандартной библиотеке Python 3 (не требует установки модулей через `pip`).

## 📦 Установка

Склонируйте репозиторий и запустите установщик от имени root:

```bash
git clone https://github.com/kosar33/incy-cli.git
cd incy-cli
chmod +x install.sh
sudo ./install.sh
```

> Установщик автоматически проверит наличие `curl`, `python3` и при необходимости загрузит официальный бинарник `xray` с правами сетевого администрирования.

## ⚡ Быстрый старт

### 1. Добавление подписки
Скопируйте вашу ссылку на подписку и выполните:
```bash
sudo incy-cli sub "https://YOUR_SUBSCRIPTION_URL"
```
*Утилита автоматически добавит необходимый параметр `?client=incy`, сгенерирует и зафиксирует уникальный HWID и загрузит список серверов.*

### 2. Подключение к серверу
Запустите интерактивный выбор:
```bash
sudo incy-cli connect
```
Или укажите номер сервера сразу:
```bash
sudo incy-cli connect 0
```

### 3. Проверка статуса
```bash
incy-cli status
```
Выведет текущий статус туннеля, выбранную страну, ваш HWID и внешний IP-адрес.

### 4. Включение автозапуска
Чтобы VPN автоматически поднимался при перезагрузке ПК и обновлял серверы раз в сутки в 04:00:
```bash
sudo incy-cli autostart on
```

### 5. Отключение VPN
```bash
sudo incy-cli stop
```

## 📖 Справочник команд

| Команда | Описание |
| :--- | :--- |
| `sudo incy-cli sub "<URL>"` | Сохранить ссылку на подписку и первично загрузить серверы |
| `sudo incy-cli update` | Принудительно обновить список нод по подписке |
| `incy-cli list` (или `ls`) | Показать нумерованный список доступных локаций и активный сервер |
| `sudo incy-cli connect [N]` | Подключиться к серверу по номеру (или открыть интерактивный выбор) |
| `incy-cli status` | Показать статус туннеля, HWID и внешний IP системы |
| `sudo incy-cli stop` | Остановить туннель и пустить трафик напрямую |
| `sudo incy-cli autostart on` | Включить запуск при старте ОС и таймер автообновления |
| `sudo incy-cli autostart off`| Отключить службу автозапуска и таймер |

## ⚙️ Структура каталогов

* `/usr/local/bin/incy-cli` — исполняемый файл утилиты.
* `/etc/incy-cli/config.json` — конфигурация клиента (постоянный HWID, ссылка на подписку, активный сервер).
* `/etc/incy-cli/servers.json` — локальный кэш списка серверов.
* `/etc/xray/config.json` — конфигурация активного ядра Xray с параметрами TUN.
* `/etc/systemd/system/incy-cli-update.timer` — системный таймер ежедневного обновления подписки.

## 🛠️ Решение проблем

Если после подключения соединение не идет:
1. Проверьте лог службы Xray:
   ```bash
   sudo journalctl -u xray -n 50 -f
   ```
2. Убедитесь, что служба запущена от пользователя `root` (необходимо для TUN):
   ```bash
   cat /etc/systemd/system/xray.service.d/override.conf
   ```
3. Проверьте, поднят ли сетевой интерфейс `xray0`:
   ```bash
   ip addr show xray0
   ```
